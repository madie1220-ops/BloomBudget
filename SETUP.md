# BloomBudget Setup Guide\n\n## Quick Start\n\nFollow these steps to get BloomBudget running on your local machine.\n\n## Prerequisites\n\n- **Node.js** 16+ ([Download](https://nodejs.org))\n- **npm** or **yarn**\n- **MongoDB** (local or [Atlas cloud](https://www.mongodb.com/cloud/atlas))\n- **Git**\n\n## Installation\n\n### 1. Clone the Repository\n\n```bash\ngit clone https://github.com/madie1220-ops/BloomBudget.git\ncd BloomBudget\n```\n\n### 2. Backend Setup\n\n```bash\ncd backend\n\n# Install dependencies\nnpm install\n\n# Create .env file with your configuration\ncp .env.example .env\n```\n\n**Edit `backend/.env` and add your values:**\n\n```env\n# MongoDB Connection\nMONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/bloombdget\n\n# JWT Configuration\nJWT_SECRET=your_super_secret_key_here_change_this\nJWT_EXPIRE=7d\n\n# Stripe (Optional for payments)\nSTRIPE_SECRET_KEY=sk_test_your_key\nSTRIPE_PUBLIC_KEY=pk_test_your_key\n\n# Server\nPORT=5000\nNODE_ENV=development\nFRONTEND_URL=http://localhost:3000\n```\n\n### 3. Frontend Setup\n\n```bash\ncd ../frontend\n\n# Install dependencies\nnpm install\n\n# Create .env file (optional)\necho \"REACT_APP_API_URL=http://localhost:5000/api\" > .env.local\n```\n\n## Running the Application\n\n### Terminal 1 - Backend Server\n\n```bash\ncd backend\nnpm run dev\n```\n\n✅ Backend runs on: `http://localhost:5000`\n✅ Health check: `http://localhost:5000/api/health`\n\n### Terminal 2 - Frontend App\n\n```bash\ncd frontend\nnpm start\n```\n\n✅ Frontend runs on: `http://localhost:3000`\n\n## API Endpoints\n\n### Authentication\n\n```bash\n# Sign Up\nPOST http://localhost:5000/api/auth/signup\n\n# Login\nPOST http://localhost:5000/api/auth/login\n\n# Get Current User\nGET http://localhost:5000/api/auth/me\n```\n\n### Partners\n\n```bash\n# Send Partnership Invitation\nPOST http://localhost:5000/api/partners/invite\n\n# Get Pending Requests\nGET http://localhost:5000/api/partners/requests\n\n# Accept Partnership\nPOST http://localhost:5000/api/partners/:partnerId/accept\n\n# Reject Partnership\nPOST http://localhost:5000/api/partners/:partnerId/reject\n\n# Get Active Partnerships\nGET http://localhost:5000/api/partners\n\n# Share Budget\nPOST http://localhost:5000/api/partners/budgets/share\n\n# Get Shared Budgets\nGET http://localhost:5000/api/partners/budgets/shared\n\n# Remove Partner\nDELETE http://localhost:5000/api/partners/:partnerId\n```\n\n## Features Implemented\n\n### ✅ Core Features\n- User authentication (signup/login)\n- Multiple subscription tiers (Free, Pro, Premium)\n- Budget tracking and management\n- Transaction logging\n- Real-time financial dashboard\n\n### ✅ Partner Features\n- Send partnership invitations by email\n- Accept/reject partnership requests\n- Share budgets with partners\n- Three permission levels (View, Edit, Full)\n- Remove partnerships at any time\n- View active and pending partnerships\n- Shared budget management\n\n### 📱 Pages\n- **Login/Signup** - Authentication\n- **Dashboard** - Financial overview and budgets\n- **Partners** - Manage partnerships and shared budgets\n- **Settings** - Account and subscription management\n- **Pricing** - Subscription tier information\n\n## Project Structure\n\n```\nBloomBudget/\n├── backend/\n│   ├── src/\n│   │   ├── models/          # Database schemas\n│   │   │   ├── User.ts\n│   │   │   ├── Partner.ts\n│   │   │   ├── SharedBudget.ts\n│   │   │   ├── Budget.ts\n│   │   │   ├── Transaction.ts\n│   │   │   └── Subscription.ts\n│   │   ├── routes/          # API endpoints\n│   │   │   ├── auth.ts\n│   │   │   ├── partners.ts\n│   │   │   ├── budgets.ts\n│   │   │   ├── transactions.ts\n│   │   │   └── subscriptions.ts\n│   │   ├── middleware/      # Custom middleware\n│   │   │   └── auth.ts\n│   │   └── server.ts        # Express app entry point\n│   ├── .env.example         # Environment template\n│   ├── package.json\n│   ├── tsconfig.json\n│   └── README.md\n├── frontend/\n│   ├── src/\n│   │   ├── pages/           # React pages\n│   │   │   ├── Login.tsx\n│   │   │   ├── Dashboard.tsx\n│   │   │   ├── Partners.tsx\n│   │   │   ├── Settings.tsx\n│   │   │   └── Pricing.tsx\n│   │   ├── App.tsx          # Main app component\n│   │   ├── index.tsx        # Entry point\n│   │   └── index.css        # Global styles\n│   ├── public/\n│   │   └── index.html\n│   ├── package.json\n│   └── tailwind.config.js\n├── docs/\n│   ├── API.md               # API documentation\n│   └── PARTNER_FEATURES.md  # Partner features guide\n├── README.md                # Project overview\n├── SETUP.md                 # This file\n└── .gitignore\n```\n\n## Troubleshooting\n\n### MongoDB Connection Issues\n\n**Error**: `MongooseServerSelectionError`\n\n**Solution**:\n1. Verify MongoDB is running (if local)\n2. Check `MONGODB_URI` in `.env` is correct\n3. Ensure IP whitelist allows your connection (if using Atlas)\n\n### Port Already in Use\n\n**Error**: `EADDRINUSE: address already in use :::5000`\n\n**Solution**:\n```bash\n# Kill process on port 5000\nlsof -ti:5000 | xargs kill -9  # macOS/Linux\nnetstat -ano | findstr :5000    # Windows\n```\n\n### Frontend Not Loading\n\n**Error**: Cannot connect to API\n\n**Solution**:\n1. Ensure backend is running on port 5000\n2. Check `REACT_APP_API_URL` in `.env.local`\n3. Clear browser cache and restart frontend\n\n### Dependencies Issue\n\n**Error**: `npm ERR! code ERESOLVE`\n\n**Solution**:\n```bash\n# Clear npm cache and reinstall\nrm -rf node_modules package-lock.json\nnpm cache clean --force\nnpm install\n```\n\n## Next Steps\n\n### To Extend the Application\n\n1. **Add Budget Routes** - Uncomment in `backend/src/routes/budgets.ts`\n2. **Add Transaction Routes** - Uncomment in `backend/src/routes/transactions.ts`\n3. **Add Subscription Routes** - Uncomment in `backend/src/routes/subscriptions.ts`\n4. **Integrate Stripe** - For payment processing\n5. **Add Email Notifications** - Using SendGrid or similar\n6. **Deploy** - To Vercel (frontend) and Heroku/Railway (backend)\n\n### Testing the Partner Feature\n\n1. Create two user accounts\n2. From User A, invite User B via email\n3. Switch to User B and accept the invitation\n4. Create a budget in User A's account\n5. Share it with User B with appropriate permissions\n6. View shared budgets from both accounts\n\n## Deployment\n\n### Frontend (Vercel)\n\n```bash\ncd frontend\nnpm run build\n# Deploy the 'build' folder to Vercel\n```\n\n### Backend (Railway/Heroku)\n\n```bash\ncd backend\n# Push to your hosting platform\n# Set environment variables in platform dashboard\n```\n\n## Support & Documentation\n\n- **API Docs**: See `docs/API.md`\n- **Partner Features**: See `docs/PARTNER_FEATURES.md`\n- **Main README**: See `README.md`\n\n## License\n\nMIT License - Feel free to use for personal or commercial projects.\n\n---\n\n**Happy Budgeting! 🌱💰**\n"
